# 云盘与 Mac 同步指南

[文档首页](README.md) · [使用指南](USER_GUIDE.md) · [同步故障排查](TROUBLESHOOTING.md#另一台电脑没有收到书或进度)

适用版本：0.5.0。Books+ 连接的是**云盘客户端同步到本机的文件夹**；账户登录、文件上传、下载由云盘客户端处理。

![Windows、云端书库、Mac 与可选 Apple Books 桥](assets/diagrams/sync-overview.svg)

## 连接两台电脑

1. 在两台电脑安装并登录同一个云盘的桌面客户端，确认两端能看到同一个文件夹。
2. 在其中一台建立 **BooksPlus Library** 空文件夹，在 **设置 → 书库 → 更改…** 选择它，初始化书库。
3. 等待该目录的书目文件同步到另一台电脑。**另一端选择已经到达的同一书库副本，不要分别初始化两个空书库再合并。** 两端的绝对路径可以不同。
4. 在另一台 Books+ 中选择对应本地目录。`catalog.json`、`catalog/`、`reader-state/` 建议设为始终保留本机；旧导出库还应保留 `records/`。
5. 在第一台导入一本书，等待云盘完成上传和下载，在第二台打开，翻页、加书签，再回第一台确认记录。

![在设置中选择云盘的本地目录；图中为隐私安全的本机演示目录](assets/screenshots/settings-library.png)

旧的 `Books Export/library.json` 导出书库可以直接连接，Books+ 不重写导出器的原始书目与记录。不要选择 Apple Books 私有容器本身。

### Google Drive

使用 Google Drive 桌面客户端把同一文件夹镜像或挂载到两台电脑，在 Books+ 中分别选择对应位置。确认 Books+ 能读写，且 JSON 与正文都进入同步范围。只有网页上的云盘地址不能作为书库路径粘贴到软件里。

### iCloud Drive

在 Windows 和 Mac 的 iCloud Drive 中找到同一份目录。正文可按需下载，小型书目和状态文件建议保留本机。Mac 上的默认 Books Export 路径是 iCloud Drive 下的普通目录，不是 Books 专用容器。

### OneDrive 与其他客户端

确认客户端正在运行、登录正常，未暂停或陷入排队。OneDrive 本轮曾出现超时，恢复同步并等待文件到达后完整闭环通过；这类客户端问题会直接影响跨端接力。

| 提供程序                      | 本轮 Windows ↔ Mac 证据 | 范围                                               |
| ----------------------------- | ----------------------- | -------------------------------------------------- |
| Google Drive                  | 通过                    | 原文 SHA-256、进度与书签、删除恢复、两台实际阅读器 |
| iCloud Drive                  | 通过                    | 同上                                               |
| OneDrive                      | 最终通过，保留首轮超时  | 同上；客户端曾未运行 / 同步排队                    |
| Dropbox、坚果云、Syncthing 等 | 未做本轮双机实测        | 兼容本地同步目录机制，不能视为逐家认证             |
| 仅网页 / 仅 API 的网盘        | 不直接支持              | 需先有可读写的本地同步或挂载目录                   |

具体步骤、延迟测量和失败记录见[0.5.0 验收报告](TESTING-0.5.0.md)。本轮延迟是测试观测，不是服务保证。

## 接着读与冲突

应用每约 5 秒及窗口聚焦时读取到达本机的新记录，打开书前再次刷新。正在阅读时收到新位置会显示提示，点击 **接着读**，或留在当前位置。

![远端位置到达时显示接着读；本图为隔离本机演示](assets/screenshots/reader-resume.png)

每台安装只写自己的快照，阅读位置、状态、偏好和标注分别按时间合并。多台电脑同时离线改同一字段时，较新时间戳优先；请保持系统时间准确。不同正文修订不能保证 CFI / 页码一致，会尝试按百分比恢复。

云盘暂时不可写时，记录先留在本机并定期重试。**书库左下角显示已写入，只能证明本地目录写入完成；上传进度还要看云盘客户端。**

![共享书库与本机配置的边界](assets/diagrams/data-locations.svg)

不要同步整个应用配置目录，不要手工把多个设备快照改成同一个 ID。正文与状态必须一起同步；只同步 EPUB 文件不会同步进度。

## 删除与恢复也会同步

在任意一台 **删除图书… → 移到最近删除**，另一台新版 Books+ 会隐藏该书；若正在读，会返回书库。在任何新版客户端恢复后，其他端会在状态到达后恢复显示。原文与记录保留，Apple Books 原件不受删除影响。

![删除、最近删除与恢复的跨端含义](assets/diagrams/delete-restore.svg)

所有参与设备需升级到 0.5.0。旧版忽略删除字段，不能据此判断删除没有同步。

## Mac 与 Apple Books

Mac 不仅可以作为 Books+ 阅读器，也可以运行 Apple Books 桥。在 **设置 → Mac 同步** 选择模式：

| 模式     | 窗口 / Dock           | Apple Books 后台同步            |
| -------- | --------------------- | ------------------------------- |
| 只阅读   | 正常阅读窗口          | 关闭                            |
| 只同步   | 隐藏 Dock，菜单栏常驻 | 运行；关闭设置窗口后继续        |
| 两者都用 | 阅读窗口与菜单栏      | 运行；关阅读窗口继续，⌘Q 才退出 |

![真实 Mac 同步设置：模式、登录项、位置回写与状态面板](assets/screenshots/mac-sync.png)

_截图的隔离示例使用“只阅读”，所以显示同步已停用。没有为了拍图读取个人 Apple Books 书库。_

### 首次启用

1. 把 Books+.app 放到 Applications。
2. 先选择正常云盘目录作为输出书库，不要选择 Books 的私有容器。
3. 选择 **只同步** 或 **两者都用**。如提示无权限，在系统设置中为 Books+ 开启 **完全磁盘访问**，然后重启应用。
4. 如需开机后台运行，启用 **登录后自动同步**，按系统要求批准登录项。
5. 查看同步状态。首次导入、正文未下载、数据库忙或映射不唯一时，等待或按面板提示处理，不能只凭按钮返回成功判断同步完成。

### 哪些能双向，哪些不能

| 内容                       | Apple Books → 云库 / Books+ | 云库 / Books+ → Apple Books                       |
| -------------------------- | --------------------------- | ------------------------------------------------- |
| 无 DRM EPUB / PDF          | 自动导出可读取的文件        | 正常导入；需核对唯一映射与正文                    |
| EPUB 阅读位置              | 导出 CFI / 百分比           | 同修订 EPUB 可用深链接尝试定位，由 Books 自行保存 |
| PDF 阅读位置               | 导出百分比                  | 不回写页码 / 百分比                               |
| 书签、高亮、笔记、完成状态 | 导出                        | 不回写                                            |
| Books+ 删除 / 恢复         | Books+ 状态随云库同步       | 不删除 Apple Books 原书                           |
| DRM、音频、`.ibooks`       | 不支持导出阅读              | 不支持                                            |

**位置回写可能将 Apple Books 带到前台。** 可关闭「自动回写 Apple Books 阅读位置」，保留书籍同步与导出，改为手动「在 Books 中继续」。

Books 可能把段内位置保存成页首 CFI，或关闭书籍窗口后才保存。出现待核对时，需要实际查看 Books 的页面后确认；不要仅凭百分比相近确认。该深链接依据本机实验，不是已确认的 Apple 稳定公开进度 API。

本轮不包含 iPhone，也不保证另一台 Apple 设备已通过 iCloud 收到记录。详细权限、映射与恢复步骤见[Mac 技术说明](MAC.md)，回写实验见[研究记录](research/apple-books-writeback.md)。
