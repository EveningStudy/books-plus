# Books+ 文档

[项目首页](../README.md) · [版本与下载](https://github.com/EveningStudy/books-plus/releases)

**从这里开始：安装 → 选择书库 → 加入图书 → 阅读 → 连接另一台电脑。**

## 当前发行边界

0.5.0 已有 Windows x64、Apple Silicon Mac 和三种云盘双机测试证据。Mac Developer ID 签名 / 公证、正式 GitHub 更新源上线和线上升级仍待完成；Intel Mac 与 iPhone 未参与本轮验收。详细状态见 [发行检查](RELEASE.md)。
