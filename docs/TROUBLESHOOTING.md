# 常见问题

[文档首页](README.md) · [使用指南](USER_GUIDE.md) · [云盘同步](SYNC_GUIDE.md)

## 另一台电脑没有收到书或进度

按顺序检查：

1. 云盘客户端是否正在运行、登录成功、没有暂停 / 排队 / 冲突？Books+ 不直接上传到服务器。
2. 两端是否连接**同一份**书库的本地副本？同名的两个空文件夹不是同一个书库。不要手动合并不同 `libraryId`。
3. `catalog.json`、`catalog/extra/`、正文与 `reader-state/` 是否都到达另一端？只复制电子书不会复制进度。
4. 等待客户端同步完成，聚焦 Books+ 或点左下角刷新。应用通常每 5 秒检查到达本机的新记录。
5. 正在阅读时，顶部是否出现 **接着读**？软件不会未经确认把当前页面跳走。
6. 系统时间是否准确？离线冲突按时间戳合并。

![收到新的远端位置后，可以选择接着读](assets/screenshots/reader-resume.png)

本机写入失败会显示错误；云盘写入失败则保留本机备份并重试。保留本机配置，直到确认记录已同步。排查前不要删除 `reader-state/` 或复制另一台电脑的设备配置。

## 有封面，但书打不开

书目和小封面可能先于正文到达。先在云盘客户端确认正文已同步、可以下载，再重试。若校验不符，不要把损坏文件当作新版本覆盖，应等正确正文到达。

DRM 加密文件无法打开。MOBI / AZW3 / DOCX 等需要 Calibre；在 **设置 → 格式支持** 检测或选择 `ebook-convert`。旧 `.doc` 不支持。TXT 乱码可改文字编码后重开。[完整格式边界](FEATURES.md#格式)

![格式支持页显示内置格式和可选转换器](assets/screenshots/settings-formats.png)

## 打开 EPUB 侧栏后，文字被截断

当前 epub.js 在部分窗口布局变化后可能没有立即重新排版。先调整一次窗口大小，或关闭侧栏再重新打开书籍。文档截图遇到此情况时通过实际调整窗口恢复排版，未修改截图像素；该布局问题仍需后续修复。

快速接受远端跳转后立刻返回书库，还可能触发 epub.js 的异步清理异常。拍摄中应用仍能继续打开其他书，但不能据此保证所有快速操作均无问题；暂可等目标章节载入后再返回。此问题也列入发行检查。

## 删除后没有节省空间

**删除图书** 是可恢复的状态操作，正文和阅读记录仍保留。要节省空间，使用 **释放本地空间** 或云盘客户端的按需下载。当前没有永久清空入口。

若另一端仍显示该书，确认所有设备都使用 0.5.0，且删除状态已经由客户端同步。Apple Books 原书不会随 Books+ 删除。

![删除和释放空间是两个独立操作](assets/diagrams/delete-restore.svg)

## 释放本地空间不可用

普通文件夹没有云端副本可供驱逐；其他提供程序也可能拒绝原生 API。正在阅读、标记保留离线、系统固定、未上传、有冲突的正文不能释放。刚导入的文件需先完成同步，并成为提供程序支持的占位文件。

Mac 仅对 iCloud Drive 启用原生释放；其他 File Provider 请使用云盘客户端管理下载。离线固定是本机行为，不自动替另一台电脑保留正文。

## 没有声音，或本地模型不能朗读

- 检查系统音量、输出设备、应用音量和暂停状态。
- Edge 需要网络，服务协议变动可能导致失败，可重试或切换本地引擎。
- 神经离线模型必须先下载完成；首次加载较慢，下载失败可重试，异常退出可切换引擎。
- 中文 / 中英混读使用 ZipVoice 或合适的 Edge 音色；英文模型不适合中文、日文、韩文。
- 扫描 PDF、漫画图片和无文字层文件需要先 OCR，本软件不提供 OCR。

语音参数与模型许可见[参考文档](FEATURES.md#朗读与字幕)。自动化静音播放不等于人工音质评价。

## 桌面字幕看不到或点不到

在 **设置 → 桌面字幕** 点击 **显示桌面字幕**。全局 **Ctrl / ⌘ + Shift + D** 切换显示；**Ctrl / ⌘ + Shift + L** 解锁鼠标穿透，再拖动位置或调整大小。设置预览只展示样式，播放时才有实际朗读字幕。

## Mac 同步没有运行

确认不是 **只阅读** 模式。把应用放在 Applications，在 **完全磁盘访问** 允许 Books+ 后重启；登录项按系统提示批准。查看同步面板的具体原因，正文未下载、Books 数据库忙或多候选映射都可能需要等待 / 核对。

位置回写可能需要 Books 自己保存，甚至在关闭书籍窗口后落库。待核对状态不能直接视为精确定位成功。详见[Mac 技术说明](MAC.md#回写与回声)。

## 检查更新失败

检查网络与发布页是否可达，再重试。更新失败不代表已是最新版，校验失败也不会允许安装。

Mac 当前本地签名包只检查版本与打开发布页；自动安装需 Developer ID 签名和正式更新配置。旧版没有更新页时，需要首次手动安装带更新器的新版本。[安装与升级](INSTALLATION.md)

## 反馈问题时提供什么

提供应用版本、系统与架构、格式 / 云盘类型、复现步骤、预期和实际结果，以及不含个人信息的截图。可以提供最小合成样本。不要公开账号、令牌、私钥、完整个人书库或私人 Apple Books 数据库。
