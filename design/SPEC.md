# Books desktop design

Reference: `books-reference.png`, generated with the built-in ImageGen tool. The user chose Mac Books. The reference shows the library, reading view, themes, narration and desktop subtitles as one coordinated system.

- Main background #ffffff; sidebar #f4f3f1; orange #e87822; primary text #262422; muted #8c8986; separators #e6e4e1.
- UI: system sans-serif, 13px controls, 12px metadata, 30px semibold library heading. Reading: Chinese serif, 21px default, 1.8 line height.
- Sidebar 220px. Open shelves with 128px covers, 36px column gaps; no enclosing cards. Real EPUB covers, restrained spine shadow, two-line titles and progress underneath.
- Reading uses a 56px toolbar, generous horizontal margins, a centered canvas, a progress row and a 64px narration bar. Six appearance themes. Theme popover right aligned below toolbar.
- Line icons from Lucide, 18px, 1.7px stroke. Selected navigation uses a pale orange fill. Focus rings and control labels remain visible to keyboard/assistive technology.
- Native Windows window controls are used on Windows. The Mac version uses its native title bar. No decorative imitation traffic lights.
- Overlay: frameless, transparent, always on top; white text with dark outline, orange current word; hover controls, adjustable background, font, line count, dimensions, alignment and mouse lock.
- Application screens: library, search and filters, EPUB reader, PDF reader, contents/notes/search drawer, reading themes, voice settings, subtitle settings, library connection.

ImageGen prompt is the initial generation request from this chat: high fidelity Mac Books Chinese library and reading window, white surfaces, light gray sidebar, orange accent, six themes, native text/line icons, narration controls and transparent subtitles. Generated book covers in the reference are conceptual only; the application extracts real covers from the user's own library.
